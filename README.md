# TrustVault

### Secure Documents. Trusted Access.

TrustVault is a web-based secure document storage application developed using Python and Flask.

## Features

- User Registration and Login
- Password Hashing
- Secure Document Upload
- File Encryption using Fernet
- Document Download and Decryption
- Delete Documents
- User-specific Document Access
- SQLite Database

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- Cryptography (Fernet)

## Installation

1. Clone the repository.
2. Install dependencies:

   pip install -r requirements.txt

3. Run the application:

   python app.py

4. Open http://127.0.0.1:5000 in your browser.
