
# TrustVault - AI Usage Log

This file records how AI assistance was used during the development of TrustVault.

## 1. November 5, 2026 - Project Structure

**Task:** Plan the structure of the TrustVault Flask application.

**AI assistance:** Helped organize the Flask application, templates, static files, database and upload directories.

**Developer contribution:** Reviewed the proposed structure and implemented the project files.

## 2. November 5, 2026 - Document Encryption

**Task:** Implement secure document storage.

**AI assistance:** Helped implement file encryption and decryption using Fernet.

**Developer contribution:** Integrated encryption into the upload and download workflow and checked that encrypted files were not readable as normal documents.

## 3. November 6, 2026 - Authentication and Authorization

**Task:** Improve user authentication and document access control.

**AI assistance:** Helped implement password hashing, login sessions, role checks and per-document read/edit permission checks.

**Developer contribution:** Integrated the authentication and authorization logic into the Flask application.

## 4. November 6, 2026 - Audit Logging

**Task:** Record security-related activities.

**AI assistance:** Helped design audit event recording and a hash-linked audit log verification mechanism.

**Developer contribution:** Integrated audit logging for important application actions and added an admin audit view.

## 5. November 6, 2026 - Security Review

**Task:** Improve protection against common web application threats.

**AI assistance:** Helped review CSRF protection, upload validation, access checks and security limitations.

**Developer contribution:** Integrated the suggested changes and documented security threats and limitations in THREATS.md.

## 6. November 6, 2026 - User Interface and Documentation

**Task:** Complete the application pages and project documentation.

**AI assistance:** Helped prepare Flask HTML templates, CSS styling and security documentation.

**Developer contribution:** Added the supplied code to the project and saved the updated files.

## Important Note

AI was used as a development assistant. The developer is responsible for reviewing, integrating and testing the generated code. Features will be reported as complete only after verification.
